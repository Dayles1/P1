# Задача: перенести новый дизайн в проект (Blade + свой CSS + ES-модули)

Скопируй папку `design-handoff/` в корень репозитория (её потом можно удалить или добавить в `.gitignore`).

В ней:
- `design/screens/*.html` — 104 экрана нового дизайна. Это обычные HTML-файлы с инлайн-стилями: открой в браузере, чтобы увидеть, и читай разметку, чтобы взять точные размеры, отступы, цвета (все цвета — `var(--ui-*)`). Инлайн-стили — только формат макета, **в проект их не переносить**: превращай в БЭМ-классы.
- `design/SCREENS.md` — какой экран соответствует какому маршруту и Blade-файлу.
- `assets/tokens.css` — готовые токены: светлая и тёмная тема, цвет акцента, отступы, шрифт, размеры контролов.
- `assets/icons.svg` — SVG-спрайт, 76 иконок (`#i-bell`, `#i-chat`…).
- `assets/icon.blade.php` — компонент иконки.

## Главные решения дизайна (соблюдать)
1. **Сайдбар — только разделы продукта**: Главная, Профиль, Чат. Новые модули будут добавляться сюда же. Настройки, сессии, уведомления, логи, админка, выход — **не в сайдбаре**.
2. **Всё личное — в меню под аватаром справа сверху** (`Account-Menu.html`): профиль-карточка, «Мой аккаунт», безопасность и сессии, уведомления, подключённые сервисы, переключатели темы (Светлая/Тёмная/Авто) и языка (RU/UZ/EN), «Что нового», «Администрирование» (только ролям), и последним пунктом «Выйти». **Выход не должен быть в правом нижнем углу.**
3. **«Мой аккаунт»** — одна страница с вертикальной навигацией (`Account-*.html`): Профиль, Безопасность, Сессии и устройства, Уведомления, Внешний вид и язык, Подключённые сервисы, Разработчикам, Что нового. Это заменяет `/settings/*` и `/sessions`.
4. **Профиль** — отдельная страница `/profile` (сейчас редирект — убрать): `Work-Profile-*.html`.
5. **Администрирование** — своя навигация (`Admin-*.html`): Управление (пользователи, все сессии, логи), Справочники (валюты, цены, организации), Настройки платформы (6 разделов).
6. **Темы**: вместо 29 палитр — `light`, `dark`, `auto` + 6 цветов акцента (`data-accent`). `ThemeCatalog` сократить, старые значения `user_settings.theme` мигрировать (светлые → `light`, тёмные → `dark`).
7. **Шрифт Onest** вместо Instrument Sans (в Instrument Sans нет кириллицы). Подключить через `bunny('Onest', { weights: [400, 500, 600, 700] })` или Google Fonts.
8. **Иконки** — только из спрайта через `<x-blade.u-i.icon>`. Все Unicode-символы (🔔 ◐ ✓ &#9635; и т.п.) удалить, в том числе в JS-шаблонах.
9. **Адаптив**: телефон < 640 — нижняя панель вкладок (Главная, Чат, Профиль, Уведомления); 640–1199 — сайдбар 72px только иконки; ≥ 1200 — сайдбар 248px; ≥ 2560 — масштаб 150%. Смотри экраны `*-Phone`, `*-1024`, `*-2K`, `*-4K`.

## Порядок работы (по этапам, после каждого — `npm run build`, `./vendor/bin/pint`, `php artisan test`, и остановись показать результат)

### Этап 1. Основа
- Разбить `resources/css/blade/app/app.css` (4581 строк) на: `tokens.css` (из пакета), `base.css`, `layout.css`, `components/*.css`, `pages/*.css`. Использовать `@layer base, layout, components, pages, utilities`.
- Удалить 29 блоков `[data-theme=...]`, оставить `tokens.css`. Обновить `theme-bootstrap.blade.php` (light/dark/auto + accent).
- Добавить утилиты вместо инлайн-стилей: `.stack`, `.row`, `.gap-*`, `.muted`, `.text-sm`, `.truncate` и т.п. Удалить инлайн-`style=` из Blade и JS-шаблонов.
- Единая система форм: оставить `.field-*`, перевести auth на них, атрибут ошибок один — `data-field-error`.
- Решить с Tailwind: не используется — убрать `@tailwindcss/vite` и `@import 'tailwindcss'` (или спросить меня).
- Иконки: спрайт в `resources/svg/icons.svg`, партиал `blade.sections.icons` в layout-ах, компонент `icon`.

### Этап 2. Каркас приложения (`layouts/authenticated.blade.php`)
- Экраны: `Work-Home-2K.html` (десктоп), `Work-Home-1024.html` (сайдбар-иконки), `Work-Home-Phone.html` (нижняя панель), `Account-Menu.html` (меню аватара), `Notif-Popover.html` (колокольчик), `Command-Palette.html` (Ctrl K).
- Шапка: поиск «Поиск и команды» + Ctrl K, кнопка «Создать», колокольчик с точкой, аватар-кнопка. Тема и язык переезжают в меню аватара.
- Сохранить `data-turbo-permanent`, `#page-layout-config`, `data-requires-role` + `hidden`.

### Этап 3. Компоненты
Обновить/дописать `components/blade/u-i/*` по доскам `UI-Inputs-Text.html`, `UI-Inputs-Choice.html`, `UI-Inputs-DateFile.html`, `UI-Overlays.html`, `UI-Navigation.html`, `Design-System.html`:
button (состояния, loading), input (префикс/суффикс, иконка, ошибка, readonly, loading), select, checkbox (включая indeterminate), radio, switch, segmented, chips, textarea со счётчиком, money-input с валютой, phone с кодом страны, code (OTP), date/range, dropzone + file-row, avatar (+ группа), badge, alert, toast (с полоской времени), modal/drawer/confirm, dropdown menu, tabs, breadcrumbs, pagination, stepper, empty-state, error-state, skeleton, progress. Пустые заглушки `feedback/loading`, `feedback/toast`, `forms/*` — дописать или удалить. `shared/modal.js`, `shared/toast.js`, `shared/confirm.js` — привести разметку к новым классам.

### Этап 4. Страницы
По таблице в `design/SCREENS.md`. Все тексты — только `__('ui.*')` / `t('*')`, добавить ключи в `lang/{ru,uz,en}/ui.php` (включая auth-страницы, которые сейчас на английском). JS-модули, которые рендерят разметку строками (`settings.js`, `chat.js`, таблицы), перевести на новые классы и иконки.

### Этап 5. Новые экраны (нужны новые маршруты — сначала согласуй со мной)
`/profile` (свой), `/users/{id}` (профиль коллеги), онбординг после регистрации, админ: карточка пользователя, приглашение, блокировка, валюты/цены/организации (домены Currency, Price, Organization уже есть — API и модели).

## Не трогать
`resources/js/actions`, `resources/js/routes`, `resources/js/wayfinder` (автоген). Логику авторизации через Sanctum-токен не менять.

Данные на экранах (имена, цифры, курсы) — примеры; реальные берутся из API.
