# Как передать дизайн в Claude Code

1. Распакуйте архив в корень Laravel-проекта — появится папка `design-handoff/`.
2. Откройте проект в терминале или VS Code и запустите Claude Code.
3. Напишите ему:

   > Прочитай design-handoff/PROMPT.md и design-handoff/design/SCREENS.md. Начни с этапа 1, после него остановись и покажи, что изменил.

4. Проверяйте каждый этап в браузере. Любой экран из `design/screens/` можно открыть двойным кликом и сравнить.

Советы:
- Идите по одному этапу, не просите «сделай всё сразу».
- Перед началом сделайте ветку: `git checkout -b redesign`.
- Если что-то выглядит не так — сделайте скриншот и отправьте сюда, в Cowork, сверю с макетом.
