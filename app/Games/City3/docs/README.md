# Летопись города 3 — рабочие заметки

Третья версия градостроителя (City Chronicle 3). Самодостаточный модуль: всё в `app/Games/City3`
(клиент, контент, PHP, миграции, своя БД) и тесты в `tests/Feature/Games/City3`.
Стартовала как копия v2 «epochs» (`resources/games/src/epochs`); v2 не трогаем.

## Что хочет заказчик (кратко, подробно — `design/brief.md`)
- Одна фиксированная карта для всех: 100 колонок × 40 рядов суши; на старте открыта полоса 30 колонок в центре
  (x 35..64) на всю глубину, расширение влево/вправо полосами. Ратуша в центре (x 49–50, ряды 19–20).
- Без мелких камней и деревьев. Сверху — горная гряда вплотную к суше (каменоломни/шахты строятся у гор),
  снизу ~20 рядов песка и дальше море до горизонта. Карта не должна «висеть в воздухе».
- Дороги развиваются в многополосные: полосы, тротуары, декор — меняется дизайн, а не цвет.
- Метро, поезд, аэропорт. Контент до 2100 года.
- Календарь течёт равномерно (1 год = 25 с при ×1), смена эпохи не прыгает годом и не меняет всё.
- Одна валюта, остальное — ресурсы; в главном интерфейсе только валюта; её облик меняется по эпохам
  (монеты → наличные → карты → цифровые).
- Продуманная экономика («сложная математика»). Новый компактный UI для всех устройств, полноценная
  мобильная версия; ориентиры — SimCity BuildIt и Clash of Clans.

## Документы
- `design/brief.md` — требования и жёсткие ограничения; `design/ui-brief.md` — бриф интерфейса.
- `design/gdd.md` — итоговый геймдизайн (если ещё нет — основа `design/concept-player.md`,
  поправки в `design/judges.md` и `design/synthesis-notes.md`). `design/sim/sim-final.mjs` — симуляция баланса
  (`node design/sim/sim-final.mjs`).
- `analysis/*.md` — разбор кода v2 со ссылками file:line (клиент City3 начинался как точная копия).
- `plans/*.md` — планы реализации отдельных слоёв.

## Как поднять на другой машине
1. `composer install && npm install`, `.env` как обычно для P1.
2. `php artisan migrate` — провайдер модуля сам создаёт БД `city3` (sqlite: `database/city3.sqlite`,
   mysql/mariadb: `<основная БД>_city3`, или задайте `CITY3_DB_DATABASE`).
3. `npm run dev` (или `npm run build`), игра: `/games/city3`.
4. Проверки: `npx tsc -p app/Games/City3/client/tsconfig.json`, `npm run test:city3`,
   `npx eslint app/Games/City3/client`, `php artisan test --compact tests/Feature/Games/City3`.

## Правила работы
- Только ветка `main`, без новых веток и worktree. После каждого готового шага — коммит и пуш.
- Не трогать чужую незакоммиченную работу (сейчас это Sandbox) и v2.
- Всё новое для игры — только внутри `app/Games/City3` и `tests/Feature/Games/City3`.
